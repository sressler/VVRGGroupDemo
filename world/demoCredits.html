This is a "ressurection" of a VRML demo created in 1998.

This VRML demo has been the result of contributions from virtually all members of the VVRG group. In addition we have "borrowed" media assets from a number of sources. In particular the original geometry of the building which comprises the main VRML environment came from the Virtual Music Museum (with their kind permission). We substantially redecorated, and added the elevator controls.
